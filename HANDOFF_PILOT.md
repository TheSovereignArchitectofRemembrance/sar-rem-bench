# Proposed blind recipient pilot — not executed

## Question and interpretation

Does a record containing operational context help a new recipient make justified reconstruction decisions compared with the final trace alone, in one declared synthetic square family?

This tests the benefit of the added information bundle. It does not isolate the SAR packet format from any other equally informative instructions. A later matched-information condition would compare the structured packet against ordinary prose carrying the same facts.

## Common preparation

Give every recipient identical instructions defining the four-vertex, one-traversal family, the meanings of vertex labels and direction, and the permitted responses: preserve, request observation, replay a particular history, or abstain on inconsistent evidence. Give the same practice example and comprehension check to both arms. Do not teach only the packet group the scoring rule.

Freeze cases, randomized order, answer keys, primary outcome, time limit, exclusions, and analysis before collecting responses. Cases should include unique, ambiguous, and contradictory evidence. A final square alone supports ambiguity; withholding evidence must not be scored as a recipient mistake.

## Assignment and scoring

Randomly assign a proposed 20 recipients, ten per arm, to trace-only or trace-plus-packet materials. Use matched underlying cases and identical task wording. Keep the assessor blind to arm where feasible. Avoid crossover that leaks the packet's answers into the trace-only condition.

For each arm, calculate the correct action set from the evidence actually supplied to that arm. Primary outcome: proportion of responses matching that arm's justified action set. Report overconfident replay separately. Secondary outcomes: completion time, comprehension, and the number of specific replay actions both justified and correctly selected. The latter can rise because information was added even if accuracy does not.

Repeated cases from one person are not independent participants. Summarize at participant level, report the between-arm difference with uncertainty, and retain raw case responses for audit. Twenty recipients is an exploratory convenience pilot, not a sample size justified for a decisive significance claim.

## Interpretation rules

A small or uncertain estimated difference is inconclusive, not proof of no benefit. Increased overconfident replay would count against the intended handoff behavior. Improved performance supports only this task, recipient group, and information bundle. More justified actions with unchanged accuracy supports accessibility under richer evidence, not necessarily improved general learning.

The current software and screenshots contain no human outcome data. Recruitment, consent, collection, and external communication have not been performed.
